# 🌐 Mini HDFS (Mini Hadoop Distributed File System)

> 🎓 **مشروع تعليمي لمحاكاة نظام الملفات الموزع Hadoop HDFS**  
> يهدف إلى فهم عملي لمفاهيم **النظم الموزعة (Distributed Systems)**، و**برمجة الشبكات (Socket Programming)**، و**التزامن (Concurrency)**.

---

## 🧭 مقدمة المشروع

يُعد **Mini HDFS** نموذجًا مبسطًا يحاكي نظام الملفات الموزع الشهير **Hadoop Distributed File System (HDFS)**.  
يهدف المشروع إلى إنشاء نظام تخزين موزع قادر على التعامل مع الملفات الكبيرة من خلال **تجزئتها إلى كتل (Chunks)** وتوزيعها على **عدة خوادم (DataNodes)**، بإشراف **خادم مركزي (NameNode)** يقوم بإدارة النظام ومتابعة أدائه.

تم تطوير هذا المشروع لأغراض **تعليمية وأكاديمية**، وذلك لتعزيز الفهم التطبيقي لآليات **التخزين الموزع** و**التواصل الشبكي بين الخوادم والعملاء** باستخدام لغة **Java**.

---

## ⚙️ هيكلية النظام (System Architecture)

يعتمد النظام على معمارية **Master–Slave**، ويتكوّن من ثلاث مكونات أساسية:

### 🧠 1. NameNode (الخادم الرئيسي)
- يمثل مركز التحكم والإدارة في النظام.  
- يحتفظ بـ **البيانات الوصفية (Metadata)** مثل أسماء الملفات، أحجامها، ومواقع الكتل المخزنة.  
- يتابع حالة خوادم التخزين (DataNodes) عبر آلية **Heartbeat** لضمان الجاهزية والاستمرارية.

### 💾 2. DataNode (خادم التخزين)
- مسؤول عن **التخزين الفعلي للبيانات**.  
- ينفذ أوامر القراءة والكتابة الواردة من الـ NameNode أو من العميل (Client).  
- يرسل إشعارات دورية (Heartbeats) إلى الـ NameNode لتأكيد أنه يعمل بشكل طبيعي.

### 💻 3. Client (تطبيق سطر الأوامر)
- يتيح للمستخدم التفاعل مع النظام من خلال واجهة سطر أوامر بسيطة.  
- يدعم مجموعة أوامر شبيهة بأوامر نظام Linux، مثل:

```bash
put <file>     # رفع ملف إلى النظام
get <file>     # تنزيل ملف من النظام
ls             # عرض الملفات والمجلدات
mkdir <dir>    # إنشاء مجلد جديد
🚀 الميزات الرئيسية (Main Features)
✅ تخزين موزع وفعّال:
يتم تقسيم الملفات إلى كتل وتوزيعها على عدة خوادم لزيادة الكفاءة.

✅ تحمل الأعطال (Fault Tolerance):
عند تطبيق ميزة النسخ المتماثل (Replication) يتم ضمان عدم فقدان البيانات في حال تعطل أحد الخوادم.

✅ واجهة تفاعلية سهلة الاستخدام:
تدعم أوامر مشابهة لأوامر Linux مما يسهل التعامل مع النظام.

✅ قابلية التوسع (Scalability):
إمكانية إضافة المزيد من خوادم التخزين (DataNodes) بسهولة دون الحاجة لتغيير البنية الأساسية للنظام.
